# ASP Exam Checker

Unealta automata pentru verificarea disponibilitatii datelor de examen practic la DECA Chisinau (Martie & Aprilie 2026).

## Incearca-l / Give it a try

**https://asp-monitor.onrender.com**

Contul nou cere un cod de invitatie. Scrie-mi si ti-l dau.

An account needs an invite code, so contact me for the pass code.

![ASP Exam Checker, varianta web](docs/screenshot.png)


## Cum functioneaza

1. Deschide automat formularul ASP si completeaza datele tale
2. Verifica disponibilitatea la **2 filiale DECA Chisinau**:
   - str. Acad. S. Radautanu, 1
   - str. Calea Iesilor, 14
   - str. Salcamilor, 28
3. Navigheaza calendarul de **2 ori per filiala** pentru a forta incarcarea zilelor
4. Afiseaza un sumar cu toate zilele libere din Martie & Aprilie 2026
5. **Browserul ramane deschis** - poti selecta data si plati direct

---

## Note

- Scriptul **nu efectueaza nicio plata** automat
- Daca o filiala apare goala, rularea a 2 runde rezolva de obicei problema
- Dupa ce gasesti o zi buna, selecteaz-o manual si plateste - dupa inchide browserul
